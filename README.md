# NxtGen Learning Academy

Welcome to NxtGen Learning Academy - empowering the next generation with future-ready education!

## About

NxtGen Learning Academy is an educational and coaching venture dedicated to making students ages 12-18 future-ready through a perfect blend of traditional and modern learning modules. We offer engaging online small group classes that add real value to students' lives.

## Website

Visit `index.html` to view the complete website featuring:

- **Hero Section**: Inspiring mission statement and main call-to-action
- **About Section**: Our educational philosophy and approach
- **Learning Modules**: 
  - Traditional Excellence (core academics, literature, math, science)
  - Modern Innovation (digital literacy, problem-solving, project-based learning)
  - Holistic Development (communication, leadership, emotional intelligence)
- **Why Choose Us**: Key benefits including engaging classes, value-driven approach, experienced mentorship
- **Booking Integration**: Multiple calls-to-action to book a free demo class

## Getting Started

To view the website locally:

1. Open `index.html` in any modern web browser
2. Or run a local web server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit http://localhost:8000
